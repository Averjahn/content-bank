# Банк контента платформы

Витрина над полным дампом платформы med-game: клинические тренажёры с содержимым
сценариев, курсы, справочники и организации с обоих серверов (tech2 и dev2).

Живая версия: https://averjahn.github.io/content-bank/

## Один способ выгрузки

```bash
python3 конвейер/spo/export_content_bank.py
```

Без флагов забирает всё, что отдаёт админ-API, складывает в `spo/out/dump/`
и пакует в `spo/out/bank-dump-<дата>.zip`. Внутри:

| Файл | Что внутри |
|---|---|
| `INDEX.md` | Что в дампе, как читать поля, чего в нём нет |
| `bank.md` | Сводка, курсы и все кейсы по семействам |
| `bank.json` / `bank.csv` / `bank_working.csv` | Тренажёры и курсы со связями |
| `courses.json` | Курсы целиком: модули, тесты, адаптивные шаги |
| `reference.json` | Темы, стили, типы тестов и вопросов, роли, города |
| `orgs.json` | Компании, подразделения, учебные группы |
| `tests/<сервер>-<id>.json` | Содержимое кейса: шаги, тексты, лабораторные, ответы |

Чтобы обновить витрину — скопировать содержимое `spo/out/dump/` в `data/`,
положить архив как `data/bank-dump.zip` и запушить.

Персональные данные (пользователи и их результаты) в дамп не попадают.
