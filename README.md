# Банк контента платформы

Витрина над выгрузкой из админ-API med-game: все клинические тренажёры и курсы
с обоих серверов, поиск по нозологии, объём кейсов, связь «кейс ↔ курс»
и кейсы, не подключённые ни к одному курсу.

Данные статические — `data/bank.json`. Пересобираются скриптом
`конвейер/spo/export_content_bank.py` (около минуты), после чего файл нужно
залить сюда заново.

## Что можно скачать

- `data/tests.zip` — содержимое всех 857 кейсов одним архивом
- `data/tests/<сервер>-<id>.json` — отдельный кейс: шаги сценария, тексты, варианты
  ответов с пометкой правильных, лабораторные показатели, изображения
- `data/bank.json`, `data/content_bank.md`, `data/content_bank*.csv` — сводные выгрузки

Всё это собирает `конвейер/spo/export_content_bank.py --content`.
