# Банк контента платформы — полный дамп 2026-08-07

Выгрузка админ-API med-game: клинические тренажёры, их содержимое, курсы, справочники и структура организаций. Снята одной командой `конвейер/spo/export_content_bank.py`.

## Что в каталоге

| Файл | Что внутри | С чего начинать |
|---|---|---|
| `bank.md` | **Каталог с описанием каждого кейса**: сюжет, что проверяется, верные ответы | Подбор кейсов под темы и сборка курсов |
| `bank_working.csv` | Рабочие кейсы таблицей, с описанием | Фильтры и сводные |
| `bank.csv` | Все кейсы со всеми полями и флагами | Когда нужен и мусор тоже |
| `bank.json` | Тренажёры и курсы со связями | Скрипты |
| `courses.json` | Курсы целиком: модули, тесты, адаптивные шаги | Разбор структуры курса |
| `reference.json` | Темы, стили, типы тестов и вопросов, роли, города | Расшифровка id |
| `orgs.json` | Компании, подразделения, учебные группы | Кто на платформе учится |
| `tests/<сервер>-<id>.json` | Полное содержимое кейса: шаги, тексты, ответы | Когда нужен сам сценарий |

**Для контекста модели берите `bank.md`** — это описание банка, а не сами тесты: по нему видно, какой кейс о чём, и из чего можно собрать курс. Полные сценарии лежат отдельно и в контекст не нужны.

## Как читать кейс

Поля тренажёра: `host, id, name, topic, family, steps, scored, flags, courses, plot, tasks, correct`. **Нозология лежит в `topic`, а не в названии**: «СМП 09 v2» — это ОКС с подъёмом ST, искать и группировать нужно по `topic`. `plot` — сюжет кейса, `tasks` — шаги, где студент принимает решение, `correct` — верные ответы этих шагов.

> Дамп снят в режиме `--fast`: содержимого кейсов и описаний в нём нет.

## Чего в дампе нет

- Пользователей и их результатов — это персональные данные, для контекста не нужны.
- Картинок: в кейсах лежат ссылки на хранилище платформы, сами файлы не выгружаются.
- Сырого JSON сценария: шаги разобраны в плоский вид, исходный формат плеера при необходимости берётся из API по id кейса.
